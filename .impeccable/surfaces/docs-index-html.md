# Surface brief — docs/index.html

Mode: Persuade. The visitor is a developer or panel operator mid-integration; success is
running the checker against their own panel.

## Direction contract

THESIS: A panel's API is a status board. Eight actions are eight rows, each either departed or
delayed, and the page refuses the category template of headline over a code block over three cards.

OWN-WORLD: Charcoal enamel board, bone-white flap glyphs, one amber accent spent only on
in-flight work, red only for a failed probe, anodised hairlines as rails, condensed signage caps
and tabular numerals. The row is the only container; nothing is nested in a card.

STORY: This checks an SMM panel's API without spending a cent. Three probes are read-only, press
Run and the board flips them to real verdicts; every row opens the exact request and response from
the spec; the command to run it on your own panel is on the board.

FIRST VIEWPORT: Full-bleed board. Masthead strip carries SMMCHECK, the API conformance label, and
the read-only promise. Column heads ACTION / STATUS / LATENCY / NOTE over a hairline. Eight rows
fill the screen, status in the centre column. Bottom rail carries the one-line command and the
primary Run control, always visible without scrolling.

FORM: the departure board (my rank 2 of 7; the roll assigned my rank 4), seed:d7ba28df05f1b8a6

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the
verdict, DESIGN.md, and every shipping raster carrying its provenance
